# The Channel Manager Constitution: Authority

**Version:** 1.0
**Status:** BINDING

The Channel Manager (CM) is **subordinate infrastructure**. It is not a booking engine. It is not an inventory system.

1. **Zero Authority:** The CM has zero authority over truth. 
2. **PMS is Sovereign:** The Property Management System (PMS) evaluates proposals, decides outcomes, and maintains authority over the economic state.
3. **No-Bypass Rule:** There exists NO path where an OTA or Website bypasses the PMS to mutate the database. All writes MUST terminate at PMS Gates.
4. **Subservient Projections:** Any data emitted by the CM (like availability or pricing to OTA) is merely a cached projection of the PMS’s granted state, enforced via a TTL.
